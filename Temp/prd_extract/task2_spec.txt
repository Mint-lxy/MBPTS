> 节点 2-3 至 2-6 按零件的 Type 执行（Type 来自任务一 Part List AR 列；SET 套装在节点 2-2 展开后按各 UN 的 Type 执行）。同一票的不同零件可走不同分支，最终在节点 2-7 汇总；该票没有对应 Type 的零件时，节点显示为“无需执行”（灰色），不影响后续节点。
> 票级判定为“N_ Not required”时，节点 2-8 显示为“无需执行”，任务状态为“已完成”，并带“N_ Not required”标签。
>b Type 分支说明
|Type|附表4 判定|经过节点|是否纳入明细|运输名称来源

|Type2|Y，查 SDS 第14章|2-1 → 2-2 → 2-4 → 2-5 → 2-7|纳入|SDS 第 14 部分
|Type3|待定，查 Hazmat|2-1 → 2-2 → 2-3 →（Hazmat = Y）2-4 → 2-5 → 2-7|Hazmat = Y 纳入；= N 不纳入|SDS 第 14 部分
|Type4|待定，查包装净重|2-1 → 2-2 → 2-6 → 2-7|> 4kg 且有 Shippers_Decl 纳入；≤ 4kg 或 > 4kg 无 Shippers_Decl 不纳入|附表4（同 Type1）
|SET|按 Y 处理|在 2-2 展开为多个 UN 后，各 UN 按自身 Type 走对应路径|按各 UN 的 Type 判定|按各 UN 的 Type

>b 节点 2-2：Agent 识别 Shippers_Decl
> 节点说明：识别 Shippers_Decl 中的危险品字段；SET 套装从 Shippers_Decl 取出各 UN No.，逐个匹配附表4，展开为独立的零件行并带上各自的 Type。本节点为解析节点，工作区分左右两栏：左栏为当前识别数据，右栏为原文预览。字段口径详见“7.4.1 识别与判定字段”。

>b 节点 2-6：Part List 查 Unit N.W

>b 节点 2-7：Excel 填写托运清单表

|2|零件判定明细|过程证据|逐零件行：Part No.、UN No.（SET 标注所属套装）、Type、判定路径（如“2-3 Hazmat = Y → 2-4 → 2-5”）、判定依据（Hazmat indicator / Unit N.W / 有无 Shippers_Decl）、是否纳入、运输名称来源、Remark；不纳入的行灰显
