### 业务背景

- **业务方**:SCM-IE / Import Operations(进口运营)
- **现状痛点**:GLC(欧线 OOCL)与 MBUSI(美线 CMA CGM)两条进口线路提单处理全人工:每周从公邮下载 AVIS/Shipper/BL、按 PDC 归档建文件夹、手工填写 AVIS/BL/Shipping Log 导入模板、登录 IES+ 逐票导入并生成预报/台账、处理 FOB Charges 差异、回写 AVIS BL status report 大表。
- **目标**:MBPTS 平台以"每周定时批量 + 邮件监听 + OCR 解析 + IES+ 自动导入 + 异常转人工"自动化两条线路,业务人员只处理异常票与核对。

## 需求摘要

### 产品定义
- **产品名称**:MBPTS UC34 Case 2 — GLC / MBUSI 进口提单(AVIS/BL)自动化
- **所属系统**:MBPTS AI Quick Win 平台(UC34)
- **功能定位**:将 GLC 欧线与 MBUSI 美线的进口提单处理(收单、归档、填模板、IES+ 导入、差异处理、状态回写)从全人工转为平台自动化 + 异常人工协同
- **使用端**:PC Web

### 核心价值
| 价值维度 | 价值描述 | 受益人群 |
|---------|--------|---------|
| 效率 | 每周批量自动处理两线提单,单票端到端自动化率 ≥80% | 进口运营 |
| 质量 | OCR + 交叉核对 + 差异捕获,异常票 100% 不漏 | 进口运营/关务 |
| 合规 | 全程证据留痕(WORM)、审计可查、修正留痕 | 审计/管理层 |
| 可维护 | PDC 对应表、模板、邮件规则等均可配置,业务自维护 | 业务老师/平台管理员 |

### 产品范围

**包含范围:**
| 模块 | 功能描述 |
|------|--------|
| 邮件监听与统一收单 | 按线路规则监听 Portal 公邮,附件按 BL 号入暂存库 + 附件台账(pending/已处理) |
| GLC 线自动处理 | 齐套判断 → 组装文件包 → 填 AVIS/BL 模板 → IES+ 导入 AVIS → DG 分支(FOB Charges)→ 生成预报 → 导入 BL → 上传附件 → 回写 |
| MBUSI 线自动处理 | gvShipLog 导出 → 筛新增登记 → 拆单子表 → 邮件取 BL → 填 Shipping Log/BL 模板 → 归档 → IES+ 导入 → 差异处理 |
| 任务中心/任务详情 | Task-Run 模型、状态筛选、整单/节点/批量重跑、节点轨迹、字段修正留痕、PDF 原文定位、证据预览 |
| 异常处理与人工协同 | Other 文件夹、缺 AVIS 挂起、美表漏数 pending、IES 差异回写 BL different、未找到发票等;人工确认后续跑 |
| 配置中心 | PDC-Customer Code 对应表、IES Port 对应表、AVIS/BL/Shipping Log 模板版本管理、邮件规则(筛选/附件角色/流程绑定/dry-run) |
| 归档与证据 | 可配置归档根(默认 SharePoint),目录层级 `<PDC>\<GLC\|MBUSI>\<运行周>\<票文件夹>`,节点证据 WORM |
| 状态回写与提醒 | 平台台账为主 + 双写回写大表;站内提醒(不发通知邮件) |

**不包含范围(后续迭代/平台侧):**
- 治理运营台、权限中心(RBAC)、提醒中心、上传中心的平台级完整需求(本 PRD 仅简述引用)
- 源系统改造(IES+、美国 Central Warehouse 网站)
- 未匹配 BL 的业务线下处理(仅记录异常并转人工)
- UC26 等其他 Case

### 业务目标与成功指标
| 目标 | 描述 | 优先级 |
|------|------|--------|
| 提效 | 两线提单处理自动化,业务只处理异常 | P0 |
| 保质 | 异常票(无配置/缺件/差异/漏数)100% 识别并转人工 | P0 |
| 可审计 | 全链路证据与操作留痕 | P1 |

| 指标 | 目标值 | 测量方法 |
|------|-------|---------|
| 单票端到端自动化率 | ≥80%(建议值) | 无需人工介入完成票数 / 总票数 |
| 异常票识别率 | 100% 不漏 | 抽查运行周台账 |
| 异常票单票人工耗时 | ≤5 分钟(建议值) | 任务详情操作日志计时 |
| 每周批量运行完成时间 | <2 小时(建议值) | 调度起止时间 |

### 用户角色与权限
| 角色 | 说明 | 涉及功能 |
|------|------|---------|
| OPERATOR 业务操作员 | 处理异常票、字段修正、安全重跑、业务核对 | 任务中心、任务详情、修正留痕 |
| MANAGER 业务主管 | 审批、对外动作确认、不可逆重跑、导出 | 审批、导出、差异确认 |
| ADMIN 平台管理员 | 规则/模板/配置发布与运维 | 邮件中心、配置中心 |
| AUDITOR 审计员 | 只读审计 | 审计日志、证据查询 |

(职责分离:主管无字段修正权,操作员无对外确认权;身份与授权由 Alice 管理)

### 非功能性需求(已知约束)
- 配置不得硬编码(邮箱、路径、重试、等待时间等)(MBUSI FR-01)
- 重跑不得产生重复行/文件夹/上传(FR-02);失败票支持检查点续跑(FR-05)
- 上传前必填校验(FR-03);每票保留源文件/输出/时间/状态/错误详情(FR-04)
- 凭证安全存储且不入日志(FR-06)
- IES+ 交互方式不限定,但须满足:绿灯(就绪)后方可上传;差异弹窗内容须完整捕获

### 风险与待确认(转设计阶段关注)
- 美表漏数补登后 Created 更新不回溯 → 依赖下轮筛选捕获 + 台账取回续跑(已确认逻辑)
- BL 与 AVIS 存在 2-3 周时间差 → 齐套判断与跨周归并是关键设计点
- PDC/ETA 缺失、必填字段缺失 → 不创建不明确文件夹/不上传不完整模板,转人工
