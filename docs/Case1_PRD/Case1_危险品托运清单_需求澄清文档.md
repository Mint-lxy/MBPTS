#### 问题2：海运任务的调度频率？ `[Business]` `待澄清`

**【答复】：** A — 每周一 00:00 执行一次，取上周一~周日数据（与原型一致）
**【状态】：** 已澄清

### [UX] 类问题

#### 问题3：失败任务重提是否需要"立即重跑"入口？ `[UX]` `待澄清`

> BRD：业务在 IES 修正数据后，按分单号或 Pre-alert creation date 批量查询筛选并重新提交，"会和下一次定时任务一起运行"。原型任务详情另有"整单重跑（生成新执行）"按钮可立即重跑。两者口径需统一。

| 选项 | 说明 |
|------|------|
| A | 仅批量重提、随下次定时任务运行（严格按 BRD） |
| B | 批量重提 + 单票立即重跑并存（按原型，BRD 基础上增强） |

**【答复】：** B — 批量重提 + 单票立即重跑并存（按原型，BRD 基础上增强）
**【状态】：** 已澄清
