## EP-1：自动化制单主链路

**用户故事：** 作为业务操作员，我希望平台按空运每日、海运每周的节奏自动完成"取数 → 制单 → 上传 → 通知 → 存档"全流程，以便到岗后直接查看结果，不再手工制作托运清单。邮件渠道的单据由监听规则兜底建票，保证不漏单。

**验收要点：**

- 空运按 Invoice Type=DGR + Pre-alert creation=当天筛选；海运按 Invoice Type=Sea + 四个 Hazmat 库房（South/West/North/East 3PL）+ 上周一~周日窗口筛选，窗口内按运单去重
- 每命中一个 HAWB/BL 生成一票独立 Task + Run#1；定时来源开始时间统一显示 00:00；同范围并发触发被拒绝（E1002）；无数据日空跑不报错
- 七节点链路完整执行并逐节点登记证据（WORM）：定时任务触发 → 附件下载与登记（IES 导出预报清单/Part list/Shipper）→ 按 UN No. 匹配初筛 → OCR 识别 Shipper（18 字段+置信度）→ 托运清单写入（表头/表体）→ IES 导入 → 邮件发送
- 三闸口生效：G1 预报/Part List 导出失败则 FAILED；G2 低置信字段（阈值建议 0.85，OPEN-C6）金色高亮转"待人工处理"；G3 无 IES 上传回执则 FAILED 转人工
- UN 初筛口径：空→NA 无需制作、SET→套装核验、剔除附表4 I 列为 N/#N/A 的行，结果写回 part list AR 列
- 清单写入口径：表头按 PDC+Invoice Type+Terminal WH 三键查附表1（无命中→该票 FAILED 并提醒维护附表1）；表体按 Type1~4 分支（Type2 查 SDS 第14章、Type3 查 Hazmat indicator、Type4 按净重 ≤4kg 判定）；SET 套装逐 UN 独立判定
- Shippers_Decl 未下载到、无 SDS、附表3 未命中均记 Remark **不阻断**流程
- 票级判定：全票无纳入明细→"N_ Not required"，不生成清单、不上传，走完全链计入已完成
- 清单以 `道路运输危险货物托运清单_BL/HAWB` 命名上传至 IES+ 预报界面文档资料，记录上传状态 Y/N
- 每次运行按模板 TPL-C1-STATUS 发 1 封状态邮件给 IO 同事：固定引导语 + 9 列状态表（含 Remark 与 Process date）；SMTP 失败自动重试 3 次后告警（E4001）；收件人为空阻断并提醒 ADMIN
- 存档：一级目录=操作日期、二级目录=BL/HAWB，存 part list / Shippers_Decl / MSDS / 完成版清单四类文件；年度操作记录 9 列按年累积命名；路径不可用告警+补偿（E5001）不阻断主流程
- 对外动作（上传 IES+、邮件外发）已发生的票，整单重跑仅 MANAGER 可操作并弹确认；已发邮件不回溯

## EP-2：工作台总览

**用户故事：** 作为业务操作员或主管，我希望打开工作台就能看到任务总量、完成、执行中、待人工处理四类指标，以便一页掌握进度、只关注需要人工介入的票，点一下就能下钻到明细。

**验收要点：**

- Case 下拉选择 Case1 后展示统计卡：总任务数 / 已完成 / 执行中 / 待人工处理
- "待人工处理"= 待上传 ∪ 有差异 ∪ 失败（按最新 Run 状态聚合，不互斥）
- 点击卡片跳转任务中心并自动带上对应筛选，可一键"清除筛选"
- 执行时间范围筛选支持起止校验（起晚于止提示错误）；无数据日卡片显示 0 不报错

## EP-3：任务中心日常操作

**用户故事：** 作为业务操作员，我希望在任务中心用日历、筛选和批量操作管理所有任务，以便快速定位异常票、批量恢复失败票；定时任务之外的临时需求，也能手动建票立即执行。

**验收要点：**

- 任务列表列示任务编号、运单号（HAWB/BL）、触发来源（自动触发=定时调度|邮件触发；人工触发=手动）、状态、执行次数、最近执行开始、当前环节；整行点击进详情；状态一律由最新 Run 推导
- 状态 chips：全部 / 已完成 / 执行中 / 待人工处理；筛选无结果有空态提示
- 任务日历（仿贡献图）：红=有待人工、黄=有执行中、绿=全完成，悬停显示当天三态票数，点击日期筛选当天任务，支持年份切换
- 组合筛选：库房多选（四个 Hazmat PDC）+ 执行时间范围（含起止校验）+ 单号搜索（HAWB/BL 模糊命中、未命中提示），条件间与关系，可一键清除
- 手动新建任务：为当前类型建票并立即生成 Run#1，开始时间显示实际触发时间，链路与留痕与定时任务一致；同运单已有执行中任务时拒绝（E1002）
- 批量下载：弹窗逐票列出可下载文件与数量（无文件票标注），确认打包下载并写审计；未勾选时提示
- 批量重跑：弹窗逐票确认，执行中任务自动跳过并提示（E1002 幂等），每票生成 R#n+1、历史只读归档；重跑仍失败状态保持失败可再次重跑
- 导出列表：导出当前筛选集合（含编号/运单号/类型/来源/状态/执行次数/最近执行），写审计

## EP-4：任务详情核查与重跑

**用户故事：** 作为业务操作员，我希望在任务详情页看清每个节点做了什么、每个字段从哪来，发现错误能就地修正、按需重跑，以便自动化结果可信、可纠、可查；历史执行随时可回溯对比。

**验收要点：**

- 头部信息完整：任务 ID、Case、BL/HAWB、触发来源、规则、当前状态、当前执行 R#n、执行次数
- 节点轨道展示七节点五态（完成/执行中/失败/待人工处理/等待）与子步骤；待人工/失败时顶部横幅说明原因并可一键前往处理节点
- 字段面板：来源标签（OCR/规则/模型/系统）+ 置信度 + 质量等级，低置信金色高亮；"定位"跳原文对应页高亮；规则/系统字段显示"无定位"及原因
- 字段修正：仅最新 Run 且非执行中可编辑；保存记录 `delta={old, tm, runNo}` 并显示"旧值→已修正"；重跑后新 Run 经 `carried.fromRun` 继承并标注；修正仅留痕无需审批；主管角色修正被服务端拒绝（职责分离 E1004）
- 节点证据卡片带证据 ID（EV-T/EV-P/EV-O 前缀+hash）并标注 WORM 防篡改；节点附件在工作区内预览；产物文件（清单 xlsx/上传回执/邮件副本 .eml）可下载并写审计
- Case1 上传区禁用：任务由系统自动从 IES+ 获取数据，无需人工上传
- R# 历史切换：可查看历次执行快照，历史整体只读并提示，提供"切回当前执行"入口；配置快照随 Run 固化（R10.4）
- 重跑两级："任务重跑"从第一节点全链重跑，"节点重跑"从当前选中节点开始、前置节点沿用；新 Run 固化配置快照+携带生效修正值；执行中拒绝（E1002）；对外动作后整单重跑仅 MANAGER 且弹确认
- 长时卡死任务：授权角色可"停止并重新触发"（阈值 OPEN-C9），停止写审计；停止瞬间恰好完成则提示不生效（原型当前无此按钮，为已知缺口）

## EP-5：邮件中心管理

**用户故事：** 作为平台管理员，我希望在邮件中心统一管理监听规则、通知模板和收发日志，以便邮件渠道的单据自动归集、状态通知发对人；没被规则认出的邮件，也有人工兜底入口。

**验收要点：**

- 邮件监听页签：仅列当前 Case 规则（如 R-DG-CN：白名单/主题关键词/附件要求 dg_note PDF 必需），含启用开关与累计命中数；停用规则不再命中新邮件
- 规则编辑两段式：基本信息与筛选条件（名称/关联流程/主题/正文关键词/发件人白名单）+ 附件要求（角色/文件名正则/类型/必需），保存校验并写审计
- 邮件模板页签：TPL-C1-STATUS 展示主题/正文/9 个参数变量/收件人（共 N 人）与配置状态；收件人可增删，校验"至少保留一位"、重复提示；保存后下次运行生效
- 邮件日志页签分"收到的邮件/已发送的邮件"：收到的含命中状态（自动命中/手动挂规则/未命中）与未命中原因；已发送的含时间/模板/收件人/主题/关联任务，支持搜索
- 未命中邮件兜底：可"挂规则"（选 Case→选规则→预览附件归类，缺必需附件明确提示由用户决定）→"手动触发"建票并自动执行；已挂规则的邮件不能改挂

## EP-6：配置中心维护

**用户故事：** 作为平台管理员，我希望清单模板和三张映射表都能在线按版本维护，以便人员、供应商、主数据变动时上传新版本即生效，旧版本随时可回查，业务规则不因变更而漂移。

**验收要点：**

- 模板配置：危险品托运清单模板支持查看/上传/删除，上传校验扩展名 .xlsx、非空、≤20MB，版本 +1 写审计
- 映射表配置：仅上传新版本（不在线编辑），版本号 +1、旧版本保留可下载；点行查看全部版本与完整列结构；表头须与列结构一致
- 附表1 三键（PDC/Invoice Type/Terminal WH）13 列；附表4 含"是否需要制作托运清单"列（Y/N/待定查 IES+ Hazmat）
- 附表1 无命中导致的失败票，补充映射后可节点重跑恢复（闭环）
- 配置变更仅对后续 Run 生效，历史 Run 按启动时快照重解释（R10.4）

## EP-7：存档与提醒

**用户故事：** 作为业务操作员或审计员，我希望存档文件和年度记录在平台内直接可浏览，任务异常时主动收到站内提醒，以便追溯取证不用翻共享盘，异常处理不用等人发现。

**验收要点：**

- Share Point 页（MBPTS 流程存档 · UC34 Case1 专用组）：目录树按 操作日期/BL-HAWB 两级组织，存四类文件；执行中/待人工票目录内仅有已产出文件；目录按修改日期倒序
- 年度操作记录表（如 2026.xlsx）平台内可预览：9 列逐票记录，未覆盖列显示 —，以 Process date 12-31 为截止按年命名
- 任务转待人工/失败/成功等事件自动生成站内提醒，铃铛红点计未读；提醒含任务编号/类型/运输方式/状态摘要，点击直达任务详情并标记已读，支持"全部已读"

## EP-8：审计与合规

**用户故事：** 作为审计员，我希望以只读身份核查全量证据链与审计日志，以便完成合规审查；危险品业务的每次自动执行、人工修正、邮件外发都有据可查。

**验收要点：**

- 审计员全部页面只读，无写入口；调用写接口服务端拒绝并记录决策（E1004）
- 证据分 trigger/process/operation 三类（EV-T/EV-P/EV-O 前缀），带 hash 防篡改、WORM 留痕
- 审计日志含时间/操作人/动作/对象/入口五要素，可搜索；授权决策记录含主体/动作/资源/允许|拒绝/策略版本
