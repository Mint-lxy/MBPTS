**项目定位**：MBPTS（Mercedes-Benz Parts Trading & Service）AI Quick Win 项目，UC34 = 进口单证自动化平台。Case 5 目标：按两条支线自动组装 **DSS 导入模板（9 字段）** 实现 ASN 自动创建。

**两条支线**：
- **MBPLAP**：每日 12:00 / 17:00 定时触发，以分单号（HAWB/BL No.）为单位，IES+ 两级导出（预报清单→PN 级发票）→ 合并加总 → DSS 模板
- **X-entry**：Portal 公邮（asn@mb.cn）邮件触发，以运单号（AWB No.）为单位，报关代理送货邮件 + IMS PO 邮件 → 诊断仪大表 → PO 阻断转人工 → 顺次收货拆行 → DSS 模板

## 需求摘要（初稿，待审批）

### 产品定义
- **产品名称**: UC34 Case 5 — ASN 自动创建（MBPLAP / X-entry 双支线）
- **所属系统**: MBPTS 进口单证自动化平台（PTS Portal）
- **功能定位**: 自动组装 DSS 导入模板（9 字段），供业务导入 DSS 创建 ASN
- **使用端**: PC Web Portal（工作台/任务中心/上传中心/邮件中心/配置中心/SharePoint/提醒中心）

### 核心价值
| 价值维度 | 价值描述 | 受益人群 |
|---------|--------|---------|
| 效率 | MBPLAP 每日两窗定时自动出模板，替代人工两级导出+手工合并加总 | IO 操作 |
| 准确 | X-entry 多 Item 顺次收货拆行自动计算，避免人工查大表算错 | IO 操作 |
| 可控 | PO 缺失硬阻断转人工补录、收货记录自动/手工并列可查、证据留痕 | BU / 主管 |

### 产品范围

**包含范围：**
| 模块 | 功能描述 |
|------|--------|
| MBPLAP 定时支线 | 12:00/17:00 定时（17:00 剔除 12:00 已运行分单号）；IES+ 预报批量导出 → 发票 PN 级导出 → 按合并键加总 → DSS 模板 |
| X-entry 邮件支线 | 公邮监控报关代理送货邮件 + IMS PO 邮件；AWB→诊断仪大表取 PN/QTY/ID No.；ID No.→MBPTS PO；PO 空硬阻断转人工补录 ID No.；顺次收货拆行 |
| 任务中心 | 任务（票）列表、状态机、手动创建/批量重跑、整单重跑/节点重跑、触发历史 |
| 上传中心 | 进口发票补传、手工收货录入（PO+PN+数量）、ID No. 补录、收货记录查询（自动+手工） |
| 邮件中心 | 监听规则管理（发件人/主题/附件角色）、试运行 dry-run、优先级 |
| 配置中心 | DSS 导入模板版本管理（9 列结构查看/上传替换） |
| SharePoint 归档 | 已完成票产出文件归档浏览（诊断仪大表 / MBPLAP\<时间戳> / X-entry\<时间戳>） |
| 提醒中心 | 待人工处理/执行成功提醒，跳转任务详情 |

**不包含范围：**
- DSS/SPM 系统侧任何动作（导入、EDI 下发、结果回传判定均人工）
- 与 DSS/SPM 的系统集成（零集成，产出到模板文件 + Portal 下载/SharePoint 归档为止）
- 旧货/GLC 补货的 GR（判定逻辑同 Case 4）

### 业务目标与成功指标
| 目标 | 描述 | 优先级 |
|------|------|--------|
| MBPLAP 定时自动出模板 | 12:00/17:00 两窗口，当日完成 | P0 |
| X-entry 邮件触发自动出模板 | 触发到跑完可接受半天时延 | P0 |
| PO 阻断可见可续 | PO 缺失→人工补录 ID No.→下次运行续跑 | P0 |
| 收货记录可查 | 自动与手工收货并列查询，每 PO 已收/订购/剩余 | P0 |

| 指标 | 目标值 | 测量方法 |
|------|-------|---------|
| 定时窗口准点率 | 目标值待定（Q54 沿用项目层） | 调度日志 |
| 模板一次导入通过率 | 目标值待定 | DSS 侧反馈 |
| 人工干预率 | 逐期下降 | 任务状态分布 |

### 用户角色与权限
| 角色 | 说明 | 涉及功能 |
|------|------|---------|
| IO（进口操作） | 日常使用、异常处理、手工收货录入 | 任务中心、上传中心、提醒中心 |
| 配置维护者 | 邮件规则、DSS 模板、维度表维护 | 邮件中心、规则编辑、配置中心 |
| BU / 主管 | 收货记录搜索查看、归档取证 | 上传中心（收货记录）、SharePoint |
| 德勤（运维） | 只读监控、协助配置 | 全模块只读/协助 |
